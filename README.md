# Govial

Go + Vial + Jovial = Govial

## Run

Requires Go 1.27.3 or later.

```sh
go tool mygo dev
```

macOS only, for now.

## Roadmap

- [x] Load the layout and keymap from a connected keyboard
- [x] Change a key to a basic keycode, then read it back
- [x] Lock and unlock
- [ ] Assign layer keys, such as `MO` and `LT`
- [ ] Edit macros
- [ ] Edit combos
- [ ] Control lighting
- [ ] Flash firmware
- [ ] Windows and Linux
